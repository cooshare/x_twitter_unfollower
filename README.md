# \# Twitter/X 批量取关脚本 - 浏览器 Console 版本

# 

# 一个可以直接在浏览器 F12 Console 中执行的 JavaScript 脚本，用于批量取消关注 Twitter/X 账号。

# 

# \## 使用方法

# 

# \### 1. 准备工作

# 

# 1\. 打开浏览器，登录 Twitter/X

# 2\. 访问你的关注页面：`https://x.com/following`

# 3\. 按 `F12` 打开开发者工具

# 4\. 切换到 `Console`（控制台）标签

# 

# \### 2. 配置白名单

# 

# 打开 `twitter\_unfollow.js` 文件，在 `CONFIG` 区域编辑白名单：

# 

# ```javascript

# const CONFIG = {

# &#x20;   // 白名单 - 这些账号不会被取关（不需要 @ 符号）

# &#x20;   whitelist: \[

# &#x20;       'elonmusk',      // 示例

# &#x20;       'twitter',       // 示例

# &#x20;       '你的好友账号',   // 添加你想保留的账号

# &#x20;   ],

# &#x20;   // ... 其他配置

# };

# ```

# 

# \### 3. 粘贴执行

# 

# 1\. 复制 `twitter\_unfollow.js` 的全部代码

# 2\. 粘贴到 Console 中

# 3\. 按回车执行

# 

# \### 4. 确认操作

# 

# \- 如果是\*\*模拟模式\*\*（`dryRun: true`），会直接显示结果

# \- 如果是\*\*实际执行\*\*（`dryRun: false`），会弹出确认对话框，点击确定后开始执行

# 

# \## 配置说明

# 

# ```javascript

# const CONFIG = {

# &#x20;   // 白名单 - 这些账号不会被取关

# &#x20;   whitelist: \[],

# 

# &#x20;   // 每次运行最大取关数量（安全限制，默认50）

# &#x20;   maxUnfollows: 50,

# 

# &#x20;   // 操作间隔时间（毫秒，默认2000ms = 2秒）

# &#x20;   delayBetweenActions: 2000,

# 

# &#x20;   // 是否开启模拟模式（true = 只显示不执行，默认false）

# &#x20;   dryRun: false,

# 

# &#x20;   // 是否自动滚动加载更多（默认true）

# &#x20;   autoScroll: true,

# 

# &#x20;   // 滚动次数（默认3次）

# &#x20;   scrollCount: 3

# };

# ```

# 

# \## 使用建议

# 

# \### 首次使用 - 模拟模式测试

# 

# ```javascript

# dryRun: true,  // 先开启模拟模式

# ```

# 

# 这样只会显示将要取关的账号，不会实际执行。

# 

# \### 安全取关

# 

# ```javascript

# maxUnfollows: 10,        // 每次只取关10个

# delayBetweenActions: 3000, // 间隔3秒

# ```

# 

# \### 批量取关

# 

# ```javascript

# maxUnfollows: 100,       // 取关100个

# scrollCount: 5,          // 多滚动几次加载更多

# ```

# \## 注意事项

# 

# 1\. \*\*页面要求\*\*：必须在 `https://x.com/following` 页面运行

# 2\. \*\*白名单\*\*：务必先配置白名单，避免误取关重要账号

# 3\. \*\*操作间隔\*\*：建议保持 2 秒以上的间隔，避免触发平台限制

# 4\. \*\*数量限制\*\*：建议每次不超过 50 个，可分多次执行

# 5\. \*\*网络稳定\*\*：执行过程中保持网络连接稳定

# 

# \## 常见问题

# 

# \### Q: 脚本没有找到任何账号？

# A: 请确保：

# \- 你在正确的页面 (`/following`)

# \- 页面已完全加载

# \- 尝试增加 `scrollCount` 值多滚动几次

# 

# \### Q: 如何停止脚本？

# A: 刷新页面即可停止。

# 

# \### Q: 白名单不生效？

# A: 检查用户名是否拼写正确，不需要加 `@` 符号。

# 

# \### Q: 取关失败？

# A: 可能是：

# \- 网络问题，请检查网络连接

# \- Twitter/X 界面更新，需要更新脚本

# \- 操作过于频繁，请增加 `delayBetweenActions`
